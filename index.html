RESEARCH PROPOSAL · CAIRO UNIVERSITY Proposed research

Diff-Aware Retrieval-Augmented Mutation Testing for Evolution-Aware Regression Test Generation

Abdullah Ahmed Ibrahim · Ahmed Abdelkarim
Computer Science Department · Cairo University

We propose DAMUTEST, a Diff-Aware Retrieval-Augmented Mutation Testing framework for reducing residual alignment in LLM-based regression test generation. The research combines semantic code-diff analysis, targeted mutant generation, retrieval of historically relevant mutant–test pairs, and iterative test refinement to ground generated tests in the semantics introduced by software changes.

01 / SEMANTIC DIFF

Identify changed code regions and classify change types such as arithmetic, boundary, boolean, and structural changes.

02 / TARGETED MUTANTS

Generate mutants within changed regions and their immediate dependencies, then filter equivalent mutants.

03 / RETRIEVAL-AUGMENTED TESTS

Retrieve semantically similar historical mutant–test pairs and use them as few-shot examples for test generation.

04 / ITERATIVE REFINEMENT

Compile and execute generated tests, repair failures, and feed surviving mutants into the next generation cycle.

Planned evaluation: CodeNet and Defects4J, compared with vanilla LLM generation, MUTGEN, and a residual-alignment baseline. The proposal defines mutation score, residual alignment rate, regression awareness, and test-suite churn as evaluation metrics.
